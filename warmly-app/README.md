# Warmly App (Expo)

## Setup

- Backend: ensure Warmly API runs on http://localhost:3000 (or set EXPO_PUBLIC_API_URL).
- Install deps:
```bash
npm install
```

## Run
```bash
npm run start
# scan QR with Expo Go (or run ios/android/web)
```

## Config

Create `.env` (or use app config) variable:
```
EXPO_PUBLIC_API_URL=http://localhost:3000
```
